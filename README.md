# 阴阳师 PC 端窗口一键复位工具 (Onmyoji Window Reset)

为《阴阳师》PC 客户端量身定制的窗口位置与尺寸一键复位工具。用于解决因误拖动窗口、意外调整大小或系统缩放导致自动化点击器/脚本坐标偏移失效的问题。

## ✨ 特性

- 🚀 **一键静默复位**：双击即用，通过 Windows 原生 VBS 引擎启动，完全无黑框闪烁。
- 🔔 **智能异常提醒**：成功复位时保持完全静默；若未开启游戏或发生异常，自动弹出 Windows 原生弹窗友好提醒。
- 🎯 **物理像素级对齐**：支持 Windows 系统级 DPI 感知（DPI-Aware），不受 125%、150% 等系统屏幕缩放比例的影响。
- 🔄 **智能状态恢复**：若游戏处于最小化或最大化状态，自动还原至常规窗口后再进行精确定位。
- 🛡️ **特权隔离适配**：自动请求以管理员权限执行 Win32 API，顺畅操控以管理员身份运行的游戏客户端。

## 📁 文件说明

- `复位窗口.vbs`：一键静默运行入口（双击此文件即可）。
- `reset_onmyoji.ps1`：核心复位逻辑脚本（调用 Win32 API 查找窗口并重置位置大小）。

## 📥 下载与安装

> [!WARNING]
> **重要存放规则：**  
> `复位窗口.vbs` 与 `reset_onmyoji.ps1` **必须存放在同一个文件夹内**，切勿拆散或单独只下载其中一个文件！

### 新手下载步骤：
1. 点击本 GitHub 页面右上角绿色的 **`Code`** 按钮；
2. 在弹出菜单中选择 **`Download ZIP`** 下载完整压缩包；
3. 将下载的压缩包完整解压到任意文件夹（例如桌面或自定义目录）；
4. 解压后确认两个核心文件位于同一目录下即可。

## 🎮 使用方法

1. 启动《阴阳师》PC 客户端；
2. 直接双击运行 `复位窗口.vbs`；
3. 弹出管理员权限确认（UAC）时点击「是」；
4. 游戏窗口将在后台瞬间自动恢复至设定的坐标与分辨率。

## ⚙️ 自定义坐标与分辨率

> [!IMPORTANT]
> **屏幕配置与基准说明：**  
> 本工具预设的默认数值是基于 **笔记本屏幕分辨率 2880 × 1800、系统缩放比例 200%** 的环境下测试调校的。  
> 
> 由于脚本开启了物理像素 DPI 感知，如果你的屏幕分辨率、缩放比例或连点器录制的基准窗口尺寸不同，**请务必根据自己的实际屏幕与需求调整下方参数**！

修改方式非常简单，只需用记事本打开 `reset_onmyoji.ps1`，修改顶部的参数即可：

```powershell
# ---------- 初始状态基准（可自行修改）----------
$InitLeft   = 288    # 窗口左上角 X 坐标（距屏幕左边缘物理像素）
$InitTop    = 198    # 窗口左上角 Y 坐标（距屏幕上边缘物理像素）
$InitWidth  = 2304   # 窗口宽度（物理像素）
$InitHeight = 1358   # 窗口高度（物理像素）
```

## ❓ 常见问题

**Q: 为什么运行需要申请管理员权限？**  
A: 《阴阳师》PC 客户端通常以管理员身份运行。Windows 的 UIPI（用户界面特权隔离）安全策略禁止普通权限程序操作管理员权限程序的窗口，因此脚本必须以同等权限执行。
